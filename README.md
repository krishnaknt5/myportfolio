# 🌟 Personal Portfolio Website - Krishna Kanta

Welcome to the official repository for my personal portfolio website! This lightweight, responsive, and modern web application showcases my background, educational journey, internship experiences, key technical skills, featured data analytics projects, and contact information.

---

## 🚀 Live Demo

Check out the live website here:  
👉 **[Krishna Kanta - Portfolio](https://krishnaknt5.github.io/myportfolio/)**

---

## ✨ Features

- **Responsive Design:** Optimized for seamless viewing across desktops, tablets, and mobile devices with a toggleable navigation menu.
- **Theme Switching (Dark / Warm Light Mode):** Features a comfortable reading mode with a soft warm sepia/cream light theme and a sleek dark theme.
- **Interactive Navigation:** Smooth scrolling to sections (`About`, `Education`, `Skills`, `Projects`, `Contact`) and a floating home button for quick navigation back to top.
- **CV Download Link:** Direct link allowing visitors to download my resume with a single click.
- **Social & Contact Links:** Quick access buttons for GitHub, LinkedIn, Twitter/X, Discord, YouTube, Email, and Phone.
- **Project Showcase:** Highlights real-world projects featuring live demos and GitHub source code links.

---

## 🛠️ Tech Stack & Tools

- **HTML5:** Semantic layout and structured markup.
- **CSS3:** Custom CSS with CSS variables, Flexbox, Grid layout, smooth scrolling transitions, and media queries.
- **JavaScript (Vanilla JS):** Clean and fast implementation for menu toggling and theme switching.
- **Font Awesome (v6.5.2):** High-quality vector icons for social media, contact channels, and UI controls.
